## 적용
- 직접 번역, 기기 캐시, 개인 빌드 내장 번역 모두 koCard()에서 확인된 표현을 정규화한다.
- 실물 검수 카드 면 15개의 효과는 실물에 맞추고 02034 호박 폭탄 재수록은 동일 효과 문구를 적용하되 검수 완료로 표시하지 않는다.
- 정규화는 숫자나 게임 규칙을 바꾸지 않는다. 비용과 효과 사이의 화살표는 원문 의미를 유지한다.
- 2023년 6월 참조 안내서에 포함된 키워드는 확인 완료. 이후 추가된 용어 및 개별 카드 문구는 별도 검수 대상이다.
- 커뮤니티 번역과 직접 번역 초안은 계속 출처를 구분한다.

### 레킹 크루 번역 초안
MarvelCDB 고정 리비전의 twc_encounter.json 카드 면 60개를 비교했다. ko 파일에도 한글 효과가 없어 실물 검수 3개 면은 유지하고 나머지 57개 면은 영문 원본을 바탕으로 직접 번역했다. 07019/07034/07048 제목만 정발 확인. 07034의 MarvelCDB 데이터는 Wrecker를 지목하지만 엔진은 Piledriver를 참조하므로 표시 초안은 Piledriver를 사용했다. 해당 실물의 조건과 능력명은 검수 필요. 07041은 원본 데이터의 회복 표현을 따랐으며 인쇄판 문구 확인 필요. 게임 엔진은 변경하지 않았다.
