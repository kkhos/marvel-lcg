# 마블 챔피언스 한국어 번역 용어집

## 근거와 범위
사용자가 2026-11-28에 제공한 한국어 실물 카드 사진 3장: 기본판 01005 거미줄 날아차기, 그린 고블린 02021 호박 폭탄, 시니스터 모티브 27002 고스트 킥. 효과 설명을 대조했다. 사진은 저장소에 포함하지 않는다. 카드 특성, 플레이버, 자원 기호의 그래픽은 이번 검수 범위가 아니다.

| 영어 | 정발판 확인 표현 | 예시 |
|---|---|---|
| Basic power | 기본 기능 | 기본 기능 사용마다 최대 1회 |
| Hero Action | 히어로 행동 | 히어로 행동(공격) |
| Hero Response | 히어로 반응 | 히어로 반응(공격) |
| Forced Response | 강제 반응 | ★ 강제 반응 |
| Deal N damage | 피해 N점을 입힙니다 | 피해 8점을 입힙니다 |
| Take N damage | 피해 N점을 입습니다 | 간접 피해 2점을 입습니다 |
| Indirect damage | 간접 피해 | 호박 폭탄 |
| Attach | 장착 | 빌런에게 장착합니다 |
| Spend | 소모 | 자원을 소모 → |
| Discard | 버림 / 버립니다 | → 이 카드를 버림 |
| After | ~한 후 | 기본 기능을 사용한 후 |
| Max 1 per basic power use | 기본 기능 사용마다 최대 1회 | 고스트 킥 |

고유명사는 카드에 인쇄된 영문 철자를 유지한다 (Ghost-Spider, Spider-Man). 일반 능력(ability)은 기본 기능(basic power)과 구분한다. 물리력 자원 2개는 사진의 물리 자원 기호 두 개를 문자로 풀어 쓴 표현이며, '물리력' 자체의 공식 번역 여부는 이번 사진에서 확인하지 못했다.

## 적용
- 직접 번역, 기기 캐시, 개인 빌드 내장 번역 모두 koCard()에서 확인된 표현을 정규화한다.
- 세 카드의 효과는 실물에 맞추고 02034 호박 폭탄 재수록은 동일 효과 문구를 적용하되 검수 완료로 표시하지 않는다.
- 정규화는 숫자나 게임 규칙을 바꾸지 않는다. 비용과 효과 사이의 화살표는 원문 의미를 유지한다.
- 다른 용어(난입, 저지, 암약, 쇄도, 강인함, 자원 이름 등)는 기존 번역을 임시로 유지한다. 추가 실물 카드와 대조 후 확정한다.
- 커뮤니티 번역과 직접 번역 초안은 계속 출처를 구분한다.
